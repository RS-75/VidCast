Configuration requise

Cette page a besoin d'un projet Firebase gratuit pour synchroniser la lecture et le chat entre les participants. Ça prend environ 5 minutes :

  1. Va sur console.firebase.google.com et crée un projet (gratuit).
  2. Dans le projet, ouvre Realtime Database → Créer une base → démarre en mode test.
  3. Dans les paramètres du projet (icône ⚙️), ajoute une application Web et copie l'objet firebaseConfig.
  4. Ouvre le fichier index.html, cherche const firebaseConfig tout en bas, et colle tes valeurs à la place.
  5. Enregistre, mets le fichier sur GitHub, active GitHub Pages dans les réglages du dépôt.

Le détail complet est aussi dans README.md.
